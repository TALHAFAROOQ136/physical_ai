# Shara'it

Physical AI aur Humanoid Robotics men ghotne se pehle, yaqeeni banaein ke aap ke pas darj zail shara'it mojood hain.

## Molooqa Ilm

### Programming Ki Maharatein

Aap ko in men maharat honi chahiye:

- **Python 3.x** - Zaida tar robotics code aur AI frameworks Python istemal karte hain
- **Buniyadi C++** - ROS 2 men Python aur C++ dono APIs hain
- **Command line** - Linux/Unix systems par Terminal operations

### Riyazi Ka Pas Manzar

In se waqfiyat:

- **Linear Algebra** - Vectors, matrices, transformations
- **Buniyadi Calculus** - Derivatives, integrals (control systems ko samjhne ke liye)
- **Probability** - Sensor noise aur uncertainty ko samjhne ke liye

### Computer Science Ke Tasawwurat

In ki samjh:

- **Object-Oriented Programming** - Classes, inheritance, polymorphism
- **Concurrent Programming** - Threads, processes, callbacks
- **Buniyadi Networking** - TCP/IP, publish-subscribe patterns

## Software Ki Shara'it

### Operating System

- **Ubuntu 22.04 LTS** (tajveez karda)
- **Windows 11** WSL2 ke sath (alternative)

## Khud Tashkhis Checklist

Agay barne se pehle, yaqeeni banaein ke aap ye kar sakte hain:

- [ ] Methods aur inheritance ke sath Python class likhein
- [ ] Terminal men navigate karein aur buniyadi commands istemal karein (`cd`, `ls`, `mkdir`)
- [ ] Samjhein ke matrix multiplication kya karta hai
- [ ] Git repository clone karein aur branches banayein
- [ ] JSON/YAML files parhein aur likhein
