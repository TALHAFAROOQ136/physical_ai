# Introduction to Physical AI & Humanoid Robotics

Welcome to the Physical AI & Humanoid Robotics textbook. This course will teach you how to build intelligent robots using modern tools and frameworks.

## Course Overview

This textbook covers four main modules:

- **Module 1**: ROS 2 - The Robotic Nervous System
- **Module 2**: Simulation - The Digital Twin
- **Module 3**: NVIDIA Isaac - The AI-Robot Brain
- **Module 4**: VLA - Vision-Language-Action

## Target Audience

This course is designed for students and professionals interested in robotics, artificial intelligence, and humanoid robot development.

## Prerequisites

Basic programming knowledge is recommended, particularly in Python. Familiarity with Linux command line is helpful but not required.
